# هیرکان پلاست — نسخه بهبودیافته سایت

## روش انتشار در GitHub Pages
1. از مخزن فعلی یک نسخه پشتیبان بگیرید یا شاخه جدید بسازید.
2. فایل `index.html` را در ریشه مخزن با نسخه موجود جایگزین کنید.
3. فایل‌های `robots.txt` و `sitemap.xml` را نیز در ریشه مخزن قرار دهید.
4. تغییرات را commit و push کنید؛ GitHub Pages باید از شاخه `main` و پوشه `/ (root)` منتشر شود.
5. پس از انتشار، سایت را در گوشی و دسکتاپ بررسی کنید و جست‌وجو و لینک‌های تماس را امتحان کنید.

## اصلاحات موجود
- رفع مشکل مخفی‌نشدن کارت‌ها با قانون CSS صریح برای `[hidden]`.
- جست‌وجوی نرمال‌شده برای حروف فارسی/عربی رایج (ی/ي/ى، ک/ك) و نیم‌فاصله.
- شمارنده صحیح ۱۲ دسته و پیام روشن برای نتیجه خالی.
- لینک واتساپ اختصاصی برای هر دسته با پیام آماده.
- طراحی واکنش‌گرا، نوار تماس ثابت در موبایل، فوکوس قابل مشاهده و پشتیبانی از reduced-motion.
- بهبود عنوان، توضیحات متا، Open Graph و داده ساختاریافته کسب‌وکار.
- افزودن `robots.txt` و `sitemap.xml`.
- استفاده از نقشه جست‌وجوی نام و آدرس به‌جای ادعای پین دقیق تأییدنشده.

## نکته‌های لازم پیش از انتشار
- آدرس فروشگاه و شماره تلفن بر اساس اطلاعات سایت فعلی درج شده‌اند؛ لطفاً صحت آن‌ها را بررسی کنید.
- پیوند تلگرام `https://t.me/Hirkanplast` از سایت فعلی برداشته شده است.
- ساعت کاری، قیمت‌ها، موجودی، ارسال، حداقل سفارش، ایمیل، آدرس ایتا و بله عمداً ساخته یا حدس زده نشده‌اند. پس از تأیید اطلاعات واقعی، می‌توان آن‌ها را اضافه کرد.
- در حال حاضر برای تصاویر نمونه از ایموجی‌های سبک استفاده شده تا سایت وابسته به تصاویر خارجی و سنگین نباشد. بهتر است بعداً عکس‌های واقعی محصولات فروشگاه جایگزین شوند.
- `canonical` و داده ساختاریافته برای دامنه فعلی تنظیم شده‌اند. اگر دامنه اختصاصی راه‌اندازی شد، باید این نشانی‌ها و تنظیمات GitHub Pages به‌روزرسانی شوند.
